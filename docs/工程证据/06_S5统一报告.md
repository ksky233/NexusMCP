## 3. 关键工程结论

- Modern 与 Legacy 复用同一业务实现，差异停留在 SDK/Interface Adapter；
- S5 Benchmark 发现并修复 Legacy 不接受 Array-root Output Schema 的正式 Adapter 缺口；
- Trace/Metric、Log、Audit 通过 Trace ID 关联，但严格最小化 Payload；
- 企业私网 Egress 使用显式 Allowlist，而不是粗暴禁用所有 Private IP；
- Audit/Publish 失败能回滚业务状态，Non-Idempotent Unknown Outcome 不重试；
- Hybrid 明显补足模糊/跨语言 Recall，但当前小数据集未证明 RRF 优于 Vector；
- Exact Vector 对 No-Match 会返回最近候选，Confidence Gate 保留为有数据后再决策的 Backlog。
