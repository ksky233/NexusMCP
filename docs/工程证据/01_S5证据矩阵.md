## 2. S5-1 Telemetry Contract

```text
Incoming W3C traceparent
→ MCP SDK Adapter
→ mcp.tools.list / mcp.tools.call SERVER Span
→ RequestContext.trace_id
→ Structured Log / Audit Correlation
```

Exporter 默认关闭：

```text
NEXUSMCP_TELEMETRY_ENABLED=false
NEXUSMCP_TELEMETRY_EXPORTER=none|console|otlp_http
NEXUSMCP_TELEMETRY_OTLP_ENDPOINT=http://collector:4318
```

## 3. Telemetry 禁止字段

- Authorization、Cookie、Token、API Key、Password、Secret；
- 完整 Tool Arguments、Result、Search Query；
- OpenAPI/RAG/Embedding 正文与 Vector；
- Principal ID、Raw Claims；
- Exception Message；
- 任意未进入 ADR-0015 白名单的 Attribute。

## 4. 下一步

`S5-2｜Security 与 Policy Regression`：先冻结企业内网场景可用的 Egress/SSRF Policy，再补 Tenant、
Principal、Secret Logging、Approval Replay 和 Policy Golden Matrix。企业内部 API 本身可能位于私网，不能
用“禁止所有 Private IP”冒充完整 SSRF 方案；需要显式 Allowlist、Metadata Hard Deny 与执行时复检。

Egress/SSRF 边界已由
[ADR-0016](../adr/0016-upstream-egress-and-ssrf-boundary.md) 冻结；下一步按该 ADR 实现 Static Policy Port、
DNS Resolver Adapter、Registry/Executor 双接缝与 Security Matrix。
