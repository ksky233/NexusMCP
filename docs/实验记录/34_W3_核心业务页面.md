# W3｜核心业务页面

> 日期：2026-08-28  
> 状态：完成

## 1. 目标

在 W2 React/SDK 基础设施和 W2.5 视觉组件上，实现可操作的 Local Web Control Plane 主链：

```text
Upstream
→ OpenAPI Import
→ Operation Review
→ ToolVersion Submit Review
→ Publish
→ Catalog / Binding
→ Approval
→ Execution / Attempt / Audit
```

页面不复制后端状态机，所有状态与 Mutation Result 均来自 Admin API。

## 2. Upstreams

- 数据库分页；
- Namespace/Status URL Filter；
- Register HTTP/OpenAPI Upstream；
- Detail 与非敏感 Config；
- Edit Owner、Endpoint、Auth Scheme、Description、Config；
- Confirm 后 Disable；
- Remote MCP 不进入表单选项；
- React Hook Form + Zod 校验 Endpoint 和 JSON Object。

## 3. Import / Review / Publish

- Active Upstream 选择；
- Fixture Source 与 Operation Allowlist；
- Import Job List/Status Filter/Detail；
- Operation Conflict 与 Review Status；
- Accept Operation，设置 Owner、Visibility、Review Notes；
- Submit ToolVersion Review；
- 使用 Expected Schema/Binding Digest Confirm Publish；
- Error/Conflict 通过 Problem Details 恢复。

W3 发现刷新后恢复 Publish 需要按 Version ID 查询 ToolVersion，因此新增：

```text
GET /admin/tool-versions/{tool_version_id}
operationId: getToolVersion
```

页面不依赖 Review Mutation 的临时内存 Result，刷新后仍能恢复 Tool ID 与 Schema Digest。

## 4. Catalog / Version / Binding

- Namespace、Tool Status、Version Status、Visibility、Side Effect Filter；
- Stable Tool Identity Detail；
- Version History；
- Input/Output Schema；
- Schema Digest、Creator、Lifecycle Time；
- HTTP Binding Config、Digest 与 Upstream ID。

Version 与 Binding 存在数据库唯一关系，但原 Query Contract 只能按 Binding ID 查询。W3 新增：

```text
GET /admin/tool-versions/{tool_version_id}/binding
operationId: getToolVersionBinding
```

Admin OpenAPI 因此从 27 个扩展为 29 个稳定 Operation。

## 5. Approval

- Status/Principal Filter；
- Pending/Approved/Rejected/Expired/Consumed；
- Tool、Principal、Policy、Expiry、Arguments Digest；
- Confirm Approve/Reject；
- Mutation 后 Query Invalidation；
- 只显示 `has_idempotency_key`，不显示 Key Value 或完整 Arguments。

## 6. Execution / Audit

- Executions 与 Audit URL View；
- Principal、Trace、Status/Outcome Filter；
- Execution Detail；
- Attempt Timeline 与 Upstream Status；
- Audit Timeline；
- Request/Trace/Policy/Reason/Error Evidence；
- Idempotency 只显示 Present/Absent；
- 不返回或渲染 Arguments、Result、Credential、Token。

非终态 Query 使用有限 Polling；页面切换和 Filter 属于 URL State。

## 7. Frontend Architecture

每个 Feature 使用相同边界：

```text
Page
→ Feature Hook
→ Feature API
→ Generated SDK + Zod Validator
→ /admin
```

- Query Key、Retry、Polling、Invalidation 由 Feature Hook 管理；
- Form Draft 由 React Hook Form 或 Local State 管理；
- Confirm Dialog 由 Base UI 管理 Focus/Escape；
- 所有业务 Route 使用 Lazy Import；
- Root `HydrateFallback` 避免 Lazy Route Console Warning；
- Search Lab 保留到 W4。
