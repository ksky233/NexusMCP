# W2.5｜Control Plane UI 基线

> 日期：2026-08-28  
> 状态：完成

## 1. 目标

在 W3 批量实现业务页面前，先把 W2 的功能型 React Shell 替换为稳定的企业治理视觉基线，避免 Table、
Form、Status、Dialog 完成后再次整体换皮。

本阶段参考本地“黑白-细硬”UI System，但只吸收视觉规则，不复制 70KB 静态 HTML、Tailwind CDN、原生 DOM
Script 或 Demo 业务。

## 2. 视觉决策

- 主色：Ink `#222831`；
- 正文/结构：Slate `#393E46`；
- 分组/Hover：Mist `#EEEEEE`；
- Canvas：`#F7F7F6`；
- Running-only：Teal `#00ADB5`；
- Error/Danger：Wine `#74303E`；
- Radius 只使用 `4px / 8px / Pill`；
- Card 使用 Thin Border + Hairline Shadow；
- 移除蓝色渐变、大圆角、彩色 Dashboard Tile 和装饰性 Glow；
- 详细规则见 [Control Plane 视觉基线](../前端/01_ControlPlane视觉基线.md)。

## 3. Shell

- Desktop White Sidebar；
- Mist Active Navigation + 2px Slate Inset Line；
- Sticky Thin Header；
- Local Development Admin 环境声明持续可见，但不使用 Error 色；
- Mobile 使用 Base UI Dialog 实现 Off-canvas Navigation、Backdrop、Focus Management、Escape 和 Close；
- Sidebar 状态保持 Local Component State，不引入 Zustand。

## 4. 基础组件

W3 可以直接使用：

- `Button`：Primary/Secondary/Ghost/Danger，Default/Small/Icon；
- `StatusPill`：Active/Completed/Pending/Review/Draft/Failed/Neutral；
- `Input`、`Textarea`、`Select`、`FieldLabel`、`FieldHelp`；
- `TableFrame/Table/Head/Body/Row/Cell`；
- Bounded Window `Pagination`；
- Base UI `ConfirmDialog`；
- Loading/Empty/Error；
- Page Title、Eyebrow、Panel、Divider。

Dropdown、Tooltip、Toast、Tabs、Segmented 和 Switch 没有真实 W3 需求前不预建。

## 5. Dashboard

- Header、Metric、Empty State、Search Projection 和 Transport Boundary 全部替换为灰阶细硬风格；
- Failed/Unknown Metric 只有非零时使用 Wine；
- Search Projection 只有存在 Pending Index 时使用 Teal Active；完成状态使用 Ink；
- Request ID、Embedding Model/Dimension 保留 Mono Evidence；
- Dashboard 改为 Lazy Route，主 Chunk 从约 `507KB` 降至 `403KB`，独立 Dashboard Chunk 约 `104KB`；
- Lazy Route 增加 `HydrateFallback`，避免浏览器 Console Warning。

## 7. 下一步

进入 W3，业务页面按以下顺序复用本阶段组件：

```text
Upstreams
→ Import / Review / Publish
→ Tool Catalog / Version / Binding
→ Approval
→ Execution / Attempt / Audit
```

W3 只在真实交互需要时扩展组件；W4 负责最终 Responsive/Accessibility/Visual QA 与作品集截图。
